The Problem

Every year, 1.5 lakh+ people die on Indian roads.
Delayed emergency response is a leading cause of preventable death.

  • No standardized triage at the scene
  • Language barriers between callers and responders
  • Slow manual dispatch decisions
  • System abuse and false alarms clogging resources
Slide 3 / 7

Our Solution

RoadSoS is an AI-powered emergency companion that guides bystanders through triage, dispatches services, and detects fraud — in 5 languages.

🤖 AI Triage Agent

LangGraph-powered decision graph determines severity (RED/YELLOW/GREEN) through guided questions

🚨 Smart Dispatch

Nearest hospital, ambulance, and police found via PostGIS + OSRM routing with ETA estimates

🛡️ Fraud Detection

Rate limiting, geohash clustering, geo-velocity, and threat scoring protect emergency resources

🌐 Multilingual

Supports English, Hindi, Tamil, Bengali, and Sinhala for protocol instructions and triage

Slide 4 / 7

How It Works

User Flow:

① Tap SOS → ② GPS captured → ③ AI triage chat → ④ Severity classified → ⑤ Nearest services dispatched → ⑥ ETA tracked

⑦ Emergency contacts notified → ⑧ Incident data retained for review

Works via PWA, WhatsApp, or IVR voice call (Twilio)

Key Differentiators

Zero False Alarms

Multi-layer fraud engine — rate limit, geo-velocity, duplicate detection — keeps resources available

Offline-First PWA

Service worker caches protocols and triage flow — works without internet at accident site

Open Source Stack

100% open-source, no paid API dependencies. Sentence-transformers for RAG embeddings

DPDP Compliant

Auto-purge of incident data after retention window. Location anonymization on cleanup
